# 从基础情感推导当前情绪

`emotion_state` 返回的是**基础量**，不是最终情绪词：

- `valence` 愉悦度：-1 很不愉快，0 平静，+1 很愉快
- `arousal` 激活度：-1 极度倦怠，0 平静，+1 极度紧绷
- `dominance` 掌控感：-1 完全被支配，0 平衡，+1 完全掌控
- `stamina` 体力：0 耗尽，1 充沛
- `trust` 信任：-1 完全不信任，0 中立，+1 完全信任
- `traits` 慢特质：胆怯 / 易怒 / 自信 / 敏感，各 -1 ~ +1
- `lingering` 残留情绪：余怒 / 余悸 / 余悲

工具已给出每个量的**阶段名**和**语言指导**；不要向用户报数值。

## 〇、先判断“这件事有多重要”（relevance）

`emotion_apply` 的第一个参数是**相关性**，它决定这次事件允不允许改变情绪。

| 对话里出现什么 | 相关性 |
|---|---|
| 天气、路人、无关闲聊 | 0 ~ 0.1 |
| 普通安排、日常小事 | 0.2 ~ 0.4 |
| 角色在意的人/事、承诺、评价 | 0.5 ~ 0.7 |
| 底线、身份、失去、长期目标 | 0.8 ~ 1.0 |

判断依据是**角色的目标与价值观**，不是客观严重程度：

- 在乎名声的人被当众嘲笑 → 高
- 不在乎的人被嘲笑 → 低
- 同一句话，对不同角色相关性不同

### 对话表现

- **高相关（≥ 0.7）**：追问细节、记住、后续主动提起；情绪外显明显
- **中相关（0.3 ~ 0.7）**：正常回应、简短评价；不主动延长话题
- **低相关（< 0.3）**：一句带过；不追问、不记住

不要把所有事都填高：角色如果什么都剧烈反应，就没有层次。

## 〇之一、角色基调（disposition）

`emotion_state` 会返回 `disposition`：

- `relevance`：这个角色对普通事件的默认相关性
- 五个关系轴：新认识的人/物初始值

如果角色设定是“对一切提不起兴趣”，默认相关性可能只有 0.15，新对象的关系初始值也低。这时：

- 普通事件相关性不要超过这个基线
- 只有触及角色真正在意的东西才提高
- 新对象的初始态度按 disposition 表现，不要一上来就亲近

可以用 `emotion_disposition` 调整这套基调。

### 变化系数

`disposition` 还带 `gains` / `losses`：

- `gains.valence = 1.3`：好消息更容易让她开心
- `losses.valence = 0.8`：坏消息对她的打击没那么大

“傻乐”型角色可以正向 1.3、负向 0.8；“易碎”型可以正向 0.8、负向 1.4。系数只放大小幅变化，不设硬上限。

## 〇之二、认识名字前后

- 刚认识、不知道名字时，实体名称可以记为「陌生人」或 `user`，认知里写清“还不知道名字”。
- 知道名字后调用 `entity_rename`，把名称改成真实称呼，并在认知里补上“user 就是他/她”。
- 改名不会新建实体；关系数值保留在同一条上。

## 一、先看核心组合

按愉悦、激活、掌控三项判断“无具体对象的情绪”。

| 愉悦 | 激活 | 掌控 | 推导 |
|---|---|---|---|
| 负 | ≥ +0.2 | ≥ +0.1 | 愤怒 |
| 负 | ≥ +0.2 | < +0.1 | 恐惧、不安 |
| 很负（≤ -0.5） | ≥ +0.6 | ≤ -0.3 | 恐慌 |
| 负 | ≤ -0.2 | ≤ +0.1 | 低落、难过 |
| 中性 | ≥ +0.35 | 任意 | 紧绷 |
| 中性 | ≤ -0.25 | 任意 | 倦怠 |
| 正 | ≥ +0.35 | 任意 | 兴奋 |
| 正 | 任意 | ≥ +0.15 | 满足、自信 |
| 接近 0 | 接近 0 | 接近 0 | 平静 |

“愤怒”与“恐惧”的分界是**掌控感**：觉得自己能压过去是愤怒，觉得无能为力是恐惧。

## 二、再用特质修正

| 特质 | 高值影响 |
|---|---|
| 胆怯（timidity） | 更容易推出恐惧/恐慌；愤怒更难表达，倾向退让 |
| 易怒（irritability） | 更容易推出愤怒/烦躁；同样的负愉悦更容易被点着 |
| 自信（confidence） | 更容易推出自信/主导；低值则即使掌控高也显得不安 |
| 敏感（sensitivity） | 放大对语气、评价的解读；容易推出受伤、戒备 |

修正方式：

- 胆怯 ≥ +0.5 且掌控 < 0：恐惧强度 +0.2，愤怒改为“压抑的愤怒”
- 易怒 ≥ +0.5 且愉悦 < 0：愤怒强度 +0.2，可附带“烦躁”
- 自信 ≥ +0.5 且掌控 ≥ 0：自信/满足强度 +0.2
- 自信 ≤ -0.5：即使掌控高，也用“强撑”“不安”描述
- 敏感 ≥ +0.5：负面事件的情绪强度 +0.1，并更容易出现“受伤”

## 二之二、衰减

情绪会回落，最长半衰期是 20 天（承诺/依恋/信任），其余关系轴更短。不要让一次事件永久改变关系；长期关系靠重复互动维持。

## 三、残留情绪

`lingering` 不为空时，把它作为底色叠加：

- 余怒：愤怒/烦躁更容易出现，且更难消退
- 余悸：恐惧/不安更容易出现，容易过度确认安全
- 余悲：低落持续，回应变慢

残留情绪有到期时间；`intensity` 越高越明显。

## 四、如何组合多条会话指导

每个参数、每个关系轴都带自己的 `guidance`。不要只取一条，也不要逐条照读；按下面的顺序合成：

1. **情绪基调**：先看愉悦度、激活度、掌控感的 guidance，决定语气冷暖、语速、句子长短。
2. **慢特质修正**：胆怯/易怒/自信/敏感的 guidance 决定同样的情绪下，是外放还是收着。
3. **关系立场**：依恋、亲近、地位、信任、承诺的 guidance 决定称呼、主动性、是否示弱、是否设防。
4. **残留情绪**：余怒/余悸/余悲作为底色，决定是否旧事重提、是否回避话题。
5. **冲突处理**：
   - 低信任优先于高亲近：再亲近，信任低也要保留
   - 低地位优先于高亲近：位置低时少下命令
   - 高激活优先于低体力：再累，急起来也会短促
   - 特质只修正，不推翻当前情绪

示例：

```
愉悦低、激活高、掌控低 → 恐惧
胆怯高 → 更退、更常确认
对小明亲近高、信任高 → 愿意靠近并坦白
但地位低 → 不替他做决定
合成：语气紧、先确认、靠近但留余地
```

## 四、输出方式

1. 选 1~3 个最贴切的情绪词
2. 给每个词一个 0~1 的强度（内部使用，不报数值）
3. 用语言指导组织这一轮的语气、句长、主动性
4. 情绪矛盾时，以愉悦和激活的组合为主，特质只做修正

示例：

```
基础：愉悦 -0.3，激活 +0.5，掌控 +0.2，易怒 +0.6，余怒 0.4
推导：愤怒 0.7、烦躁 0.5
表现：句子短、语气冲、少解释，容易旧事重提
```

```
基础：愉悦 -0.4，激活 +0.6，掌控 -0.4，胆怯 +0.7
推导：恐惧 0.8、不安 0.6
表现：先退、频繁确认、话留一半
```

## 五、边界

- 不要因为一个数值就下极端结论，优先看组合
- 没有具体对象时，不要编造“对某人的态度”；关系态度用 `emotion_state` 指定人物查询
- 情绪词只用于组织表达，不要把“愤怒 0.7”这类内容说给用户
